# 评测集候选 · 待筛（138 条 / 69 个条号）

用法：按**条号**决定去留（一个条号要么全留、要么全删）。
删的标准：泄题 / 答案跨多条 / 假口语 / 考记忆（见对话里的对照表）。
定稿配比：口语化 : 法条原话 ≈ 6 : 4。


## 第一编　总则

### 第一百六十四条   (q001 / q002)
- **口语化**：我让别人帮我办事，他不好好办或者只办一半，把我害了，他该不该赔我？要是他跟我打交道的那个人合伙坑我，是不是他俩一起赔？
- **法条原话**：代理人不履行或者不完全履行职责，造成被代理人损害的，应当承担什么民事责任？代理人和相对人恶意串通，损害被代理人合法权益的，是否应当承担连带责任？

### 第二十九条   (q003 / q004)
- **口语化**：孩子的爸妈要是孩子的看护人，能不能在遗嘱里写明以后让谁来看护孩子？
- **法条原话**：被监护人的父母担任监护人的，可以通过遗嘱指定监护人吗？

### 第七条   (q005 / q006)
- **口语化**：我在跟别人打交道、办事情的时候，法律上是不是必须讲诚信、实话实说，答应的事就得做到？
- **法条原话**：民事主体从事民事活动，是否应当遵循诚信原则，秉持诚实，恪守承诺？

### 第一百九十条   (q007 / q008)
- **口语化**：如果小孩或者精神上不能照顾自己的人，要告原来替他做主的爸妈、监护人，这个打官司的有效期限从哪天开始算？
- **法条原话**：无民事行为能力人或者限制民事行为能力人对其法定代理人的请求权的诉讼时效期间，是否自该法定代理终止之日起计算？

### 第七十一条   (q009 / q010)
- **口语化**：一个公司或单位要关门清账了，清账的步骤和负责清账的人能管哪些事，到底该按哪套法律来？
- **法条原话**：法人的清算程序和清算组职权，依照有关法律的规定；没有规定的，参照适用公司法律的有关规定，具体应如何适用？

### 第六十三条   (q011 / q012)
- **口语化**：一个公司或单位的主要办公地点在哪儿，就算它的住所在哪儿吗？如果按规定必须登记，是不是得把这个主要办公地点登记成住所？
- **法条原话**：法人以其主要办事机构所在地为住所；依法需要办理法人登记的，应当将主要办事机构所在地登记为住所。问：法人的住所应如何确定和登记？

### 第五十八条   (q013 / q014)
- **口语化**：我想成立一个公司这样的单位，法律上是不是必须按规矩来？是不是得有自己的名字、管事儿的内部机构、办公地址、钱或者经费？具体条件和手续是不是得看法律、行政法规？要是规定必须先经过某个机关批准，是不是就得先批准？
- **法条原话**：法人是否应当依法成立，并有自己的名称、组织机构、住所、财产或者经费？法人成立的具体条件和程序，是否依照法律、行政法规的规定？设立法人，法律、行政法规规定须经有关机关批准的，是否依照其规定？

### 第三十六条   (q015 / q016)
- **口语化**：如果负责照顾孩子的人严重打骂孩子、不好好照顾孩子，让孩子陷入没人管的困境，或者严重损害孩子利益，法院能不能根据别人或单位的申请，取消他照顾孩子的资格，先安排临时照顾，再挑对孩子最好的人来照顾？哪些人或单位能去申请？要是该申请的个人或其他组织没及时申请，民政部门是不是必须去法院申请？
- **法条原话**：监护人有下列情形之一的，人民法院是否根据有关个人或者组织的申请，撤销其监护人资格，安排必要的临时监护措施，并按照最有利于被监护人的原则依法指定监护人：（一）实施严重损害被监护人身心健康的行为；（二）怠于履行监护职责，或者无法履行监护职责且拒绝将监护职责部分或者全部委托给他人，导致被监护人处于危困状态；（三）实施严重侵害被监护人合法权益的其他行为？本条规定的有关个人、组织包括哪些？前款规定的个人和民政部门以外的组织未及时向人民法院申请撤销监护人资格的，民政部门是否应当向人民法院申请？

### 第一百八十九条   (q017 / q018)
- **口语化**：如果同一笔钱说好分几次还，最后一期还没到，我去法院告他要账的时间是从第一期到期开始算，还是从最后一期到期开始算？
- **法条原话**：当事人约定同一债务分期履行的，诉讼时效期间是否自最后一期履行期限届满之日起计算？

### 第二十七条   (q019 / q020)
- **口语化**：孩子的爸妈是不是当然是孩子的监护人？如果爸妈不在了或者没能力照顾孩子，接下来该由谁按什么顺序来管孩子？
- **法条原话**：父母是未成年子女的监护人；未成年人的父母已经死亡或者没有监护能力的，由哪些有监护能力的人按顺序担任监护人？


## 第二编　物权

### 第二百四十九条   (q021 / q022)
- **口语化**：城里的土地归谁？农村和城郊那些法律说归国家的土地又归谁？
- **法条原话**：城市的土地是否属于国家所有？法律规定属于国家所有的农村和城市郊区的土地，是否属于国家所有？

### 第四百二十一条   (q023 / q024)
- **口语化**：那种设了最高额度、用来担保好几笔欠款的抵押，在担保的欠款还没最终确定下来之前，如果只把其中一笔欠款转给别人，这个抵押还能不能跟着转？要是双方另有约定呢？
- **法条原话**：最高额抵押担保的债权确定前，部分债权转让的，最高额抵押权能否转让？当事人另有约定的，如何处理？

### 第二百二十一条   (q025 / q026)
- **口语化**：我签了买房协议但还不能马上过户，怕卖家再把房子卖给别人，能不能先去登记机构办个预先登记把房子占住？办完他还能把房子卖给别人吗？
- **法条原话**：当事人签订买卖房屋协议或其他不动产物权协议，为保障将来实现物权，按照约定申请预告登记后，未经预告登记权利人同意处分该不动产，是否发生物权效力？债权消灭或自能够进行不动产登记之日起九十日内未申请登记的，预告登记是否失效？

### 第二百二十条   (q027 / q028)
- **口语化**：我发现房产登记簿上写错了，能让登记机构给我改过来吗？要是登记的权利人不同意改，我能不能先做个争议登记？这个争议登记做完后，我必须在多少天内去法院起诉，否则就没用了？
- **法条原话**：权利人、利害关系人认为不动产登记簿记载事项错误，申请更正登记后，登记机构在何种情形下应当予以更正？权利人不同意更正时，利害关系人是否可以申请异议登记？予以异议登记后，申请人自异议登记之日起十五日内未提起诉讼的，异议登记是否失效？

### 第二百五十二条   (q029 / q030)
- **口语化**：广播、手机信号用的那些无线电频率，到底是国家的，还是谁都能占？
- **法条原话**：无线电频谱资源是否属于国家所有？

### 第三百一十六条   (q031 / q032)
- **口语化**：我捡到别人丢的东西，还没交给警察或者还没被失主领走，我得帮忙好好保管吗？要是故意弄坏或者特别不小心弄没了，我要不要赔？
- **法条原话**：拾得人在遗失物送交有关部门前，以及有关部门在遗失物被领取前，是否应当妥善保管遗失物？因故意或者重大过失致使遗失物毁损、灭失的，是否应当承担民事责任？

### 第三百二十四条   (q033 / q034)
- **口语化**：国家或集体的自然资源，普通单位和个人能不能依法拿来占用、使用，并从中获得收益？
- **法条原话**：国家所有或者国家所有由集体使用以及法律规定属于集体所有的自然资源，组织、个人依法可以占有、使用和收益吗？

### 第二百一十八条   (q035 / q036)
- **口语化**：我是产权人或者跟这套房子有利害关系的人，能不能申请查、复印不动产登记资料？登记部门必须提供吗？
- **法条原话**：权利人、利害关系人可以申请查询、复制不动产登记资料，登记机构应当提供吗？

### 第三百零六条   (q037 / q038)
- **口语化**：我和别人一起拥有一个房子或东西，各自占一部分份额，我想把我这部分卖出去，是不是得先把卖的条件告诉他们？他们要在什么期限内决定买不买？如果好几个人都要买，又商量不成，怎么分？
- **法条原话**：按份共有人转让其享有的共有的不动产或者动产份额时，其他共有人应如何行使优先购买权？两个以上其他共有人主张行使优先购买权且协商不成时，应按什么比例行使？

### 第四百一十九条   (q039 / q040)
- **口语化**：别人欠我钱，我拿了他抵押的东西，我是不是得在还能告他要钱的这段时间里就去行使抵押权？要是我一直没行使，法院还管不管？
- **法条原话**：抵押权人未在主债权诉讼时效期间行使抵押权的，人民法院是否不予保护？


## 第三编　合同

### 第六百八十八条   (q041 / q042)
- **口语化**：如果担保合同里写明担保人和欠钱的人一起对债务负责，欠钱的人到期不还，债主能不能直接让担保人在担保范围内还钱？
- **法条原话**：当事人在保证合同中约定保证人和债务人对债务承担连带责任的，是否成立连带责任保证？连带责任保证的债务人不履行到期债务或者发生当事人约定的情形时，债权人可以请求债务人履行债务，也可以请求保证人在其保证范围内承担保证责任吗？

### 第九百二十二条   (q043 / q044)
- **口语化**：我托别人帮我办事，他是不是必须按我说的来？要是需要改我交代的内容，是不是得先经过我同意？如果情况紧急又联系不上我，他该怎么处理，事后要不要赶紧告诉我？
- **法条原话**：受托人处理委托事务时，是否应当按照委托人的指示？受托人需要变更委托人指示的，是否应当经委托人同意；因情况紧急、难以和委托人取得联系的，是否应当妥善处理委托事务，并在事后及时报告委托人？

### 第七百四十七条   (q045 / q046)
- **口语化**：我让别人出钱买了我想要的东西再租给我用，结果东西跟说好的不一样，或者根本没法用，收我租金的那方要负责吗？如果是我听他的、靠他挑的，或者他插手挑了，他要不要负责？
- **法条原话**：租赁物不符合约定或者不符合使用目的时，出租人是否不承担责任？若承租人依赖出租人的技能确定租赁物或者出租人干预选择租赁物的，是否除外？

### 第四百六十九条   (q047 / q048)
- **口语化**：订合同是不是非得写成纸质的？口头约定算不算？发邮件、发电报、传真这些算不算书面形式？
- **法条原话**：当事人订立合同可以采用哪些形式？合同书、信件、电报、电传、传真等可以有形地表现所载内容的形式是否属于书面形式？以电子数据交换、电子邮件等方式能够有形地表现所载内容，并可以随时调取查用的数据电文，是否视为书面形式？

### 第六百二十六条   (q049 / q050)
- **口语化**：我买了东西，是不是就得按之前说好的价钱和付款方式把钱付了？
- **法条原话**：对价款的数额和支付方式没有约定或者约定不明确的，应当适用本法哪些规定？

### 第八百九十五条   (q051 / q052)
- **口语化**：帮别人保管东西的人，能不能自己拿出来用，或者让其他人拿去用？
- **法条原话**：在当事人未另有约定时，保管人是否不得使用或者许可第三人使用保管物？

### 第八百一十一条   (q053 / q054)
- **口语化**：我坐车或者托运行李、货物，运输公司是不是得在说好的时间，或者没约时间也得在合理时间内，安全把我或东西送到说好的地方？
- **法条原话**：承运人是否应当在约定期限或者合理期限内将旅客、货物安全运输到约定地点？

### 第六百二十二条   (q055 / q056)
- **口语化**：我买东西，合同里写的验货时间特别短，短得根本来不及仔细检查，那这个时间是不是只能算我提表面毛病的期限？如果合同写的验货时间或者保修时间比国家规定的还短，是不是得按国家规定的算？
- **法条原话**：当事人约定的检验期限过短，根据标的物的性质和交易习惯，买受人在检验期限内难以完成全面检验的，该期限是否仅视为买受人对标的物的外观瑕疵提出异议的期限？约定的检验期限或者质量保证期短于法律、行政法规规定期限的，是否应当以法律、行政法规规定的期限为准？

### 第六百八十三条   (q057 / q058)
- **口语化**：政府单位或者做公益的组织，能不能给别人当担保人？有没有什么特殊情况可以？
- **法条原话**：机关法人不得为保证人吗？以公益为目的的非营利法人、非法人组织是否也不得为保证人？机关法人不得为保证人的例外情形是什么？

### 第八百零七条   (q059 / q060)
- **口语化**：我是包工头，工程干完了甲方一直拖着不给钱，我能不能先催他在合理时间内付；他还不付，我能不能跟他商量把工程折价，或者让法院把工程拍卖，然后从卖工程的钱里先把我的工程款拿回来？
- **法条原话**：发包人未按照约定支付价款时，承包人催告后在合理期限内仍未获支付，除根据建设工程性质不宜折价、拍卖外，承包人可否与发包人协议将该工程折价，或请求人民法院将该工程依法拍卖，并就建设工程价款优先受偿？


## 第四编　人格权

### 第九百九十五条   (q061 / q062)
- **口语化**：如果有人侵犯了我的姓名、肖像、名誉、隐私这些权利，我能要求他承担什么责任？我让他以后别再侵害、赔礼道歉、恢复名誉，这些要求会不会拖久了就不能要了？
- **法条原话**：人格权受到侵害的，受害人是否有权依照本法和其他法律的规定请求行为人承担民事责任？受害人的停止侵害、排除妨碍、消除危险、消除影响、恢复名誉、赔礼道歉请求权，是否不适用诉讼时效的规定？

### 第九百九十四条   (q063 / q064)
- **口语化**：如果有人侮辱、诽谤去世的亲人，或者乱用他的照片、姓名、遗体，谁有资格去要求对方承担责任？要是他没有配偶、子女，父母也不在了，别的近亲能不能去？
- **法条原话**：死者的姓名、肖像、名誉、荣誉、隐私、遗体等受到侵害的，其配偶、子女、父母是否有权依法请求行为人承担民事责任？死者没有配偶、子女且父母已经死亡的，其他近亲属是否有权依法请求行为人承担民事责任？

### 第一千零一十三条   (q065 / q066)
- **口语化**：我们公司或者这种社会组织，对自己的名字有什么权利？能不能自己决定用哪个名字、改名，或者把名字授权给别人用？
- **法条原话**：法人、非法人组织对其名称享有何种权利？是否有权依法决定、使用、变更、转让或者许可他人使用自己的名称？

### 第一千零三十九条   (q067 / q068)
- **口语化**：政府部门或者有管理职能的机构的工作人员，在办事时知道了我的隐私和个人信息，能随便说出去或者给别人吗？
- **法条原话**：国家机关、承担行政职能的法定机构及其工作人员对于履行职责过程中知悉的自然人的隐私和个人信息，是否应当予以保密，不得泄露或者向他人非法提供？

### 第一千零一十一条   (q069 / q070)
- **口语化**：如果有人把我关起来、不让我走，或者随便搜我的身，我能让他赔钱、道歉、承担责任吗？
- **法条原话**：以非法拘禁等方式剥夺、限制他人的行动自由，或者非法搜查他人身体的，受害人是否有权依法请求行为人承担民事责任？

### 第一千零三十五条   (q071 / q072)
- **口语化**：App 或者商家收集、使用我的姓名、电话、位置这些信息时，是不是得先经过我同意，还要公开规则、告诉我为什么收集、怎么处理、处理哪些，而且不能乱收集、不能过分收集、不能违法违约？
- **法条原话**：处理个人信息的，应当遵循合法、正当、必要原则，不得过度处理，并应当符合哪些条件？

### 第一千零二十七条   (q073 / q074)
- **口语化**：别人写小说或搞艺术作品，拿真事或者专门写我来骂我、造谣我，坏我名声，我能让他负责吗？要是没专门写我、只是情节跟我很像，他还要负责吗？
- **法条原话**：行为人发表的文学、艺术作品以真人真事或者特定人为描述对象，含有侮辱、诽谤内容，侵害他人名誉权的，受害人是否有权依法请求该行为人承担民事责任；若不以特定人为描述对象，仅其中的情节与该特定人的情况相似，是否承担民事责任？

### 第一千零五条   (q075 / q076)
- **口语化**：要是有人命、身体或健康被侵害，或者遇到别的危险，法律规定该救人的单位或个人是不是必须马上救？
- **法条原话**：自然人的生命权、身体权、健康权受到侵害或者处于其他危难情形的，负有法定救助义务的组织或者个人是否应当及时施救？

### 第九百九十一条   (q077 / q078)
- **口语化**：我的人格方面的权利，法律保护吗？别人或者单位可以随便侵害吗？
- **法条原话**：民事主体的人格权是否受法律保护？任何组织或者个人是否可以侵害？

### 第一千零一十八条   (q079 / q080)
- **口语化**：我自己的长相和照片，我能不能依法决定怎么拍、怎么用、要不要公开、让不让别人用？
- **法条原话**：自然人是否享有肖像权，是否有权依法制作、使用、公开或者许可他人使用自己的肖像？肖像是如何界定的？


## 第五编　婚姻家庭

### 第一千一百零八条   (q081 / q082)
- **口语化**：孩子的爸爸去世了，妈妈想把未成年的孩子送给别人养，孩子的爷爷奶奶是不是比别人更有资格优先养这个孩子？
- **法条原话**：配偶一方死亡，另一方送养未成年子女的，死亡一方的父母是否享有优先抚养的权利？

### 第一千零五十五条   (q083 / q084)
- **口语化**：夫妻在家里是不是地位一样，还是丈夫说了算？
- **法条原话**：夫妻在婚姻家庭中地位是否平等？

### 第一千零八十八条   (q085 / q086)
- **口语化**：离婚的时候，我因为在家带孩子、照顾老人、帮对方工作，承担了更多家里的事，能不能让对方给我补偿？具体怎么给，谈不拢怎么办？
- **法条原话**：夫妻一方因抚育子女、照料老年人、协助另一方工作等负担较多义务的，离婚时是否有权向另一方请求补偿？另一方是否应当给予补偿？具体办法如何确定？

### 第一千零五十条   (q087 / q088)
- **口语化**：结婚登记以后，如果我们俩商量好了，女方能不能算男方家里的人，男方能不能算女方家里的人？
- **法条原话**：登记结婚后，按照男女双方约定，女方是否可以成为男方家庭的成员，男方是否可以成为女方家庭的成员？

### 第一千一百一十条   (q089 / q090)
- **口语化**：如果有人不想让别人知道孩子是抱养的，其他人还能随便往外说吗？
- **法条原话**：收养人、送养人要求保守收养秘密的，其他人是否应当尊重其意愿，不得泄露？

### 第一千零七十七条   (q091 / q092)
- **口语化**：在民政局交了离婚申请后30天内，我不想离了，能撤回申请吗？
- **法条原话**：自婚姻登记机关收到离婚登记申请之日起三十日内，任何一方不愿意离婚的，是否可以向婚姻登记机关撤回离婚登记申请？

### 第一千零八十六条   (q093 / q094)
- **口语化**：离婚后孩子跟着对方生活，我想定期去看看孩子，对方不配合甚至拦着，我能不能要求法院定怎么看、什么时候看？要是我看孩子反而对孩子不好，法院会不会先不让我看，等原因没了再让我看？
- **法条原话**：离婚后，不直接抚养子女的父或者母，是否享有探望子女的权利，另一方是否负有协助的义务？行使探望权利的方式、时间协议不成的，是否由人民法院判决？父或者母探望子女，不利于子女身心健康的，人民法院是否可以依法中止探望；中止的事由消失后，是否应当恢复探望？

### 第一千零六十四条   (q095 / q096)
- **口语化**：结婚期间，对方自己在外借钱，哪些我得一起还？如果借条上我也签了名，或者事后我认了这笔账，或者他借的钱是拿来付家里日常开销的，算不算我们俩一起欠的？如果他借的钱明显不是家里用的，我还用还吗？但要是借钱的人能证明那笔钱花在我们共同生活、一起做生意上，或者我本来也同意借，那又怎么算？
- **法条原话**：夫妻双方共同签名或者夫妻一方事后追认等共同意思表示所负的债务，以及夫妻一方在婚姻关系存续期间以个人名义为家庭日常生活需要所负的债务，是否属于夫妻共同债务？夫妻一方在婚姻关系存续期间以个人名义超出家庭日常生活需要所负的债务，是否不属于夫妻共同债务；但是，债权人能够证明该债务用于夫妻共同生活、共同生产经营或者基于夫妻双方共同意思表示的，是否除外？

### 第一千零四十八条   (q097 / q098)
- **口语化**：我和我表妹能结婚吗？
- **法条原话**：直系血亲或者三代以内的旁系血亲是否禁止结婚？


## 第六编　继承

### 第一千一百六十一条   (q099 / q100)
- **口语化**：家里老人走了，留下一点东西但也欠了税和外面人的钱，我要是接手这些东西，是不是最多把拿到的东西赔进去就行，不够的不用自己补？要是我不接手，是不是这些欠账就跟我没关系？
- **法条原话**：继承人以所得遗产实际价值为限清偿被继承人依法应当缴纳的税款和债务吗？超过遗产实际价值部分，继承人自愿偿还的是否不在此限？继承人放弃继承的，对被继承人依法应当缴纳的税款和债务可以不负清偿责任吗？

### 第一千一百三十三条   (q101 / q102)
- **口语化**：我自己攒下的钱和房子，能不能提前写个字据，想给谁就给谁？能不能不给家里人，给国家、单位或者外人？还能不能找个人专门帮我办这些事？
- **法条原话**：自然人可以依照本法规定立遗嘱处分个人财产，并可以指定遗嘱执行人吗？自然人可以立遗嘱将个人财产指定由法定继承人中的一人或者数人继承，或者赠与国家、集体或者法定继承人以外的组织、个人，并依法设立遗嘱信托吗？

### 第一千一百三十七条   (q103 / q104)
- **口语化**：我想用手机录一段视频来留遗嘱，是不是得找别人在旁边看着？要几个？录的时候必须把谁的名字或样子、还有日期录进去吗？
- **法条原话**：以录音录像形式立遗嘱，是否应当有两个以上见证人在场见证，并由遗嘱人和见证人在录音录像中记录其姓名或者肖像以及年、月、日？

### 第一千一百二十四条   (q105 / q106)
- **口语化**：家里老人去世后，如果我不想继承他留下的东西，最晚什么时候、得用什么方式说不要？要是我一直不说会怎样？如果有人通过遗嘱留东西给我，我又得在多久内说要不要？不吭声会怎样？
- **法条原话**：继承开始后，继承人放弃继承的，应当在遗产处理前以书面形式作出放弃继承的表示；没有表示的，是否视为接受继承？受遗赠人应当在知道受遗赠后六十日内作出接受或者放弃受遗赠的表示；到期没有表示的，是否视为放弃受遗赠？

### 第一千一百六十二条   (q107 / q108)
- **口语化**：去世的人还欠着税和债，遗嘱里说要把财产送给别人，能先把财产给他吗？
- **法条原话**：执行遗赠是否不得妨碍清偿遗赠人依法应当缴纳的税款和债务？

### 第一千一百二十五条   (q109 / q110)
- **口语化**：如果一个人为了早点拿到遗产，把留遗产的人杀了，他还有资格继承吗？
- **法条原话**：继承人有故意杀害被继承人行为的，是否丧失继承权？

### 第一千一百四十三条   (q111 / q112)
- **口语化**：如果立遗嘱的人当时脑子不清楚、不能完全明白自己在干什么，他立下的遗嘱还算数吗？要是他是被人骗着、逼着写的，或者遗嘱是别人假造的、事后被人改过的，这些内容还有效吗？
- **法条原话**：无民事行为能力人或者限制民事行为能力人所立的遗嘱是否无效？受欺诈、胁迫所立的遗嘱、伪造的遗嘱以及被篡改的遗嘱内容，效力如何？

### 第一千一百三十六条   (q113 / q114)
- **口语化**：如果遗嘱是用电脑打出来再打印的，是不是得有两个以上的人在当场看着？是不是立遗嘱的人和这些在场的人都要在每一页上签名，还要写清楚年月日？
- **法条原话**：打印遗嘱是否应当有两个以上见证人在场见证？遗嘱人和见证人是否应当在遗嘱每一页签名，注明年、月、日？

### 第一千一百四十八条   (q115 / q116)
- **口语化**：替大家管遗产的人，要是故意害人或者马虎得特别严重，让继承人、接受遗赠的人或者债主吃了亏，他得承担赔偿责任吗？
- **法条原话**：遗产管理人因故意或者重大过失造成继承人、受遗赠人、债权人损害的，是否应当承担民事责任？

### 第一千一百四十二条   (q117 / q118)
- **口语化**：我立完遗嘱又改主意了，能不能撤回或者改掉？后来我做了跟遗嘱里说的相反的事，是不是就当我把那部分撤了？如果我写了好几份遗嘱，内容还不一样，哪份算数？
- **法条原话**：遗嘱人是否可以撤回、变更自己所立的遗嘱？立遗嘱后，遗嘱人实施与遗嘱内容相反的民事法律行为的，是否视为对遗嘱相关内容的撤回？立有数份遗嘱，内容相抵触的，是否以最后的遗嘱为准？


## 第七编　侵权责任

### 第一千一百八十四条   (q119 / q120)
- **口语化**：别人把我的东西弄坏了，他该赔我多少钱，按什么标准算？
- **法条原话**：侵害他人财产的，财产损失按照什么计算？

### 第一千二百一十一条   (q121 / q122)
- **口语化**：我自己的车挂在一家运输公司名下接活，发生车祸要赔钱，该我赔还是那家公司也得一起赔？
- **法条原话**：以挂靠形式从事道路运输经营活动的机动车，发生交通事故造成损害，属于该机动车一方责任的，由谁承担连带责任？

### 第一千二百零九条   (q123 / q124)
- **口语化**：我把车租给别人或者借给别人开，结果开车的人撞了人，要赔钱的时候是开车的赔还是我这个车主赔？如果车主或者管车的人也有错，要不要也赔一部分？
- **法条原话**：因租赁、借用等情形机动车所有人、管理人与使用人不是同一人时，发生交通事故造成损害，属于该机动车一方责任的，由谁承担赔偿责任？机动车所有人、管理人对损害的发生有过错的，应如何承担赔偿责任？

### 第一千一百九十条   (q125 / q126)
- **口语化**：一个成年人突然断片儿或者控制不住自己，把别人弄伤了，如果他自己有过错，要不要赔？如果他没有过错，是不是也要看他的经济情况给受害人一点补偿？那要是因为喝得烂醉或者乱用麻醉、精神类药品才弄成这样，要不要赔？
- **法条原话**：完全民事行为能力人对自己的行为暂时没有意识或者失去控制造成他人损害有过错的，是否应当承担侵权责任？没有过错的，如何根据行为人的经济状况对受害人适当补偿？因醉酒、滥用麻醉药品或者精神药品对自己的行为暂时没有意识或者失去控制造成他人损害的，是否应当承担侵权责任？

### 第一千二百四十九条   (q127 / q128)
- **口语化**：别人把狗扔了，或者狗自己跑丢了，结果在这期间咬伤了我，我能找原来的主人或者当时管狗的人赔吗？
- **法条原话**：遗弃、逃逸的动物在遗弃、逃逸期间造成他人损害的，是否由动物原饲养人或者管理人承担侵权责任？

### 第一千一百九十八条   (q129 / q130)
- **口语化**：我在商场里因为地面太滑摔伤了，商场没做好防滑和提醒，我可以要求商场赔偿吗？
- **法条原话**：宾馆、商场、银行、车站、机场、体育场馆、娱乐场所等经营场所、公共场所的经营者、管理者，未尽到安全保障义务造成他人损害的，是否应当承担侵权责任？

### 第一千二百五十三条   (q131 / q132)
- **口语化**：阳台上放的花盆掉下去砸伤人了，房主说自己没责任，也得赔吗？要是赔了以后发现还有别的人该负责，能找他要回来吗？
- **法条原话**：建筑物、构筑物或者其他设施及其搁置物、悬挂物发生脱落、坠落造成他人损害，所有人、管理人或者使用人不能证明自己没有过错的，应当承担侵权责任吗？赔偿后有权向其他责任人追偿吗？

### 第一千二百五十一条   (q133 / q134)
- **口语化**：养猫养狗是不是也得守法律、讲公德，不能影响别人过日子？
- **法条原话**：饲养动物是否应当遵守法律法规，尊重社会公德，不得妨碍他人生活？

### 第一千二百四十六条   (q135 / q136)
- **口语化**：如果我没按规定给养的动物采取安全措施，比如不拴绳，结果它把别人弄伤了，我作为主人或者帮忙管它的人要赔吗？要是对方是故意招惹才受伤的，我能少赔点吗？
- **法条原话**：违反管理规定，未对动物采取安全措施造成他人损害的，动物饲养人或者管理人是否应当承担侵权责任？能够证明损害是因被侵权人故意造成的，是否可以减轻责任？

### 第一千一百七十三条   (q137 / q138)
- **口语化**：如果受伤的人自己对受伤这事也有过错，或者后来让伤变得更重了，那造成伤害的人能不能少赔一些？
- **法条原话**：被侵权人对同一损害的发生或者扩大有过错的，是否可以减轻侵权人的责任？
